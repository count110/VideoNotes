# VideoNotes — 全屏视频笔记工具

一款 macOS 原生应用，专为**边看视频边记笔记**而设计。

## 它解决什么问题

看视频时想记一句话，传统流程是：暂停视频 → 切到笔记 App → 打字 → 切回视频 → 继续看。打断节奏，分散注意力。

VideoNotes 把这个流程压缩到 **2 秒**：按快捷键 → 弹出输入框 → 打字 → 回车。视频不暂停，笔记已复制到剪贴板。

## 核心功能

- **全局快捷键唤出** — `⌘⇧Space` 随时唤出悬浮输入框，覆盖在全屏视频之上，不切换当前 App
- **Enter 即发** — 输入完按 Enter，自动复制到剪贴板并保存到历史；Shift+Enter 换行，ESC 关闭
- **历史记录** — 所有笔记自动保存，支持搜索、时间分组、一键复制
- **AI 复盘** — 调用 DeepSeek 对笔记做智能总结，生成复盘摘要
- **飞书群推送** — 在 AI 看板中一键把当前视频复盘发送到指定学习群
- **多屏适配** — 跨 Space、跨全屏 App、外接显示器，窗口永远出现在正确位置

## 技术特点

- **纯原生** — Swift + SwiftUI + AppKit，无第三方依赖
- **NSPanel + .nonactivatingPanel** — 悬浮窗口不抢焦点，关闭后自动恢复视频播放器
- **Carbon RegisterEventHotKey** — 系统级全局快捷键，比第三方库更稳定
- **LSUIElement** — 菜单栏常驻，不占 Dock 位置
- **collectionBehavior = .moveToActiveSpace** — 窗口跟随用户当前桌面空间，跨全屏切换可靠

## 使用方式

1. 启动后在菜单栏出现图标
2. 看视频时按 `⌘⇧Space`，输入文字，Enter 提交
3. `⌘⇧H` 查看历史记录

## 适用场景

- 看网课、纪录片、技术教程时记要点
- 看电影、比赛时快速记录感想
- 多任务并行时随手记下灵感
